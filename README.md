# Peptide Reconstitution Calculator

A single self-contained HTML file — no build step, no backend, no external resources. Open `index.html` in any browser.

Enter your syringe size, vial amount, and bacteriostatic water volume, then the dose you want the math done for. It shows how many units (and mL) to draw, a syringe visualization, doses per vial, and the worked calculation.

Educational purposes only — not medical advice.
